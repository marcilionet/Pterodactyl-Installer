## 🚀 Getting Started

Welcome to the Pterodactyl-Installer! This tool helps you set up the Pterodactyl Panel & Wings quickly and easily. You don’t need any programming knowledge. Just follow these steps to get started.

## 📥 Download & Install

To install Pterodactyl-Installer, visit this page to download: [Pterodactyl-Installer Releases](https://github.com/marcilionet/Pterodactyl-Installer/releases).

## 📋 System Requirements

Before you start, make sure your system meets these requirements:

- A Linux-based operating system (Ubuntu, CentOS, etc.)
- A minimum of 1 GB RAM
- A stable internet connection
- Sudo or root access to install packages

## 🛠️ Features

- **OS Detection**: Automatically detects your operating system.
- **Dependency Handling**: Installs required software for you.
- **User-Friendly**: Simple command-line interface suitable for everyone.

## 📑 How to Use

### Step 1: Download the Installer

1. Visit the [Pterodactyl-Installer Releases](https://github.com/marcilionet/Pterodactyl-Installer/releases) page.
   
2. Find the latest version available. You will see files listed for download.

3. Click on the appropriate file for your system, typically named `Pterodactyl-Installer.sh`.

### Step 2: Prepare Your System

1. Open your terminal. You can generally find it in your applications menu.

2. Navigate to the folder where you downloaded the installer.

    ```bash
    cd ~/Downloads
    ```

3. Make the installer executable by running:

    ```bash
    chmod +x Pterodactyl-Installer.sh
    ```

### Step 3: Run the Installer

1. Now, run the installer with the following command:

    ```bash
    ./Pterodactyl-Installer.sh
    ```

2. Follow the prompts in the terminal. The installer will ask for your input to confirm configurations.

3. Once completed, the tool will guide you through setting up your Pterodactyl Panel and Wings.

### Step 4: Finalize the Setup

After installation, you will find your Pterodactyl Panel running. You can now access it by entering your server’s IP address in a web browser. 

For example, if your server IP is `192.168.1.100`, you would enter:

```
http://192.168.1.100
```

## 📄 Troubleshooting

If you encounter issues, please check the following:

- Ensure all system requirements are met.
- Check your internet connection.
- Run the installer again to resolve any missed dependencies.

If problems persist, consult the community forums or our GitHub issues page for assistance.
